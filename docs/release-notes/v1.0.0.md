## 🎯 Tray Killer v1.0.0 — 첫 릴리스

트레이에 눌러앉은 불청객, 이제 그만. 지정한 앱을 **트레이에서 몰아내고, 다시 못 올라오게** 막아 주는 Windows 상주 앱입니다.

### 주요 기능
- ⚡ **실시간 감시** — 대상 앱이 시작되는 순간 종료 (관리자 모드에서는 커널 프로세스 이벤트 사용)
- 🧹 **정기 청소** — 5초~5분 주기로 놓친 프로세스와 되살아난 시작 항목 정리
- 🚫 **자동 시작 차단** — 레지스트리 Run/RunOnce(HKCU·HKLM·WOW6432Node), 시작프로그램 폴더, 작업 스케줄러, 서비스까지. 모두 백업하고 언제든 복원
- 👻 **유령 아이콘 제거** — 강제 종료로 남는 트레이 아이콘을 대신 지움
- 🙈 **Windows 11 트레이 숨김** — 대상 앱 아이콘을 숨김 영역으로
- 🏁 **가장 먼저 시작** — 관리자 권한 작업 스케줄러 로그온 작업으로, 다른 트레이 앱보다 먼저 자리를 잡음
- 🔄 **자동 업데이트** — GitHub Releases에서 새 버전을 받아 SHA-256 검증 후 스스로 교체
- 🇰🇷 / 🇺🇸 한국어·영어 UI

### 설치
`TrayKiller.exe`를 내려받아 실행 → UAC 한 번 승인하면 끝. (`%LOCALAPPDATA%\Programs\TrayKiller`에 설치되고 시작 메뉴·앱 목록에 등록됩니다.)

> Windows 10 1903+ / Windows 11, .NET Framework 4.8(Windows 기본 탑재) — 별도 런타임 설치가 필요 없습니다.

---

**English** — Tray Killer keeps chosen apps out of your Windows system tray: it kills them the instant they start, switches off every auto-start entry (with one-click restore), wipes ghost icons, starts before every other tray app and updates itself from GitHub Releases.
