## 🛠️ Tray Killer v1.0.1

### 수정
- **관리자 모드 시작 오류 수정** — 관리자 권한으로 실행할 때 실시간 감시(`Win32_ProcessStartTrace`) 쿼리가 거부되어 시작이 중간에 멈추던 문제를 고쳤습니다. (창이 열리지 않고 명령에 응답하지 않던 증상)
- 실시간 감시를 시작하지 못하더라도 앱의 나머지 기능(정기 청소, 창, 트레이 메뉴)은 정상적으로 동작하도록 방어 코드를 추가했습니다.

v1.0.0을 쓰고 있다면 자동 업데이트로 교체되며, 트레이 아이콘 우클릭 → **업데이트 확인**으로 바로 받을 수도 있습니다.

---

**English** — Fixes elevated startup: the real-time watcher's WMI query was rejected, which stopped startup halfway (no window, no command handling). The watcher can no longer take the rest of the app down.
