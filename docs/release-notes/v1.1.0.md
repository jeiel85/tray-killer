## 🔒 Tray Killer v1.1.0 — 보안 강화

관리자 권한으로 상주하는 앱이라, **일반 권한 프로그램이 Tray Killer를 발판 삼아 권한을 올릴 수 있는 경로**를 모두 막았습니다. 기존 설치본은 자동 업데이트 시 알아서 옮겨 갑니다.

### 바뀐 점
- **설치 위치 이동**: `%LOCALAPPDATA%\Programs\TrayKiller` → `C:\Program Files\TrayKiller`. 관리자 로그온 작업이 실행하는 exe를 일반 권한으로 바꿔치기할 수 있던 문제를 막았습니다.
- **데이터 보호**: 설정과 복원 데이터가 `C:\ProgramData\TrayKiller\<사용자 SID>`로 옮겨집니다. 관리자만 쓸 수 있고, 미리 만들어진 폴더나 링크로 바꿔치기된 폴더는 신뢰하지 않습니다.
- **복원 검증**: 복원하기 전에 Tray Killer가 원래 차단하는 위치인지 항상 다시 확인합니다.
- **시작프로그램 폴더**: 사용자 폴더의 항목은 파일을 옮기지 않고 작업 관리자와 같은 `StartupApproved` 플래그로 끕니다.
- **작업 등록 파일**: 관리자 작업 정의 파일을 사용자 `%TEMP%`가 아닌 보호 폴더에서 다룹니다.
- **디버그 명령 제한**: `snap` 명령이 임의 경로에 파일을 쓰지 못하게 했습니다.
- **최소 권한**: 명령 채널은 현재 사용자만 열 수 있고, 다른 사용자 세션의 프로세스는 건드리지 않습니다. `SeDebugPrivilege`는 필요한 순간에만 켜고, 브라우저와 폴더는 일반 권한으로 엽니다.
- **업데이트 검증**: 이 저장소의 릴리스 URL만 받고, SHA-256과 파일 버전이 모두 맞아야 교체합니다.
- **시작 설정**: "Windows 시작 시 실행"을 꺼도 로그온 작업은 남기고 트리거만 끕니다. 시작 메뉴로 실행할 때 UAC가 다시 뜨지 않습니다.
- 시작 메뉴 바로가기와 앱 목록 항목이 모든 사용자용으로 등록됩니다.

### 업데이트
v1.0.x는 자동 업데이트로 받으면 첫 실행 때 자동으로 옮겨 갑니다. 설정, 대상 앱, 차단 기록이 그대로 유지되고 이전 설치 폴더는 정리됩니다.

---

**English** — Security hardening. The elevated exe moves to `Program Files`, and settings and restore data move to an admin-only `ProgramData` store, so a non-admin program can no longer swap the exe run by the elevated logon task or tamper with data that drives privileged actions. Also included: restore re-validation, no file moves in user-writable folders while elevated (Startup items use the `StartupApproved` flag), task XML kept out of `%TEMP%`, the `snap` command confined, the command channel limited to the current user, only this session's processes touched, `SeDebugPrivilege` on demand, unelevated URL/folder opening, and stricter update checks. Existing installs migrate automatically.
